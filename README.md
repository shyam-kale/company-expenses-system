# 💼 ExpenseFlow - Complete Expense Management System

💼 Full-stack Expense Management System with React + FastAPI. Features: Dashboard, Analytics, Invoices, Team Management, Budget Tracking & CSV Export

## 🚀 Quick Start

**Windows:**
```bash
START.bat
```

Then open: http://localhost:3000

## ✨ Features

- 📊 **Dashboard** - Financial overview with charts
- 💰 **Expenses** - Full CRUD operations
- 📈 **Analytics** - 4 interactive charts
- 📋 **Reports** - Export CSV/PDF/Excel
- 💳 **Budget** - Editable budget planning
- 🏷️ **Categories** - Category management
- 👥 **Team** - Team member management
- 📅 **Calendar** - Calendar view
- 🧾 **Invoices** - Invoice management
- ⚙️ **Settings** - User settings

## 🎓 Tech Stack

- **Frontend**: React 18, Recharts, CSS3
- **Backend**: Python 3.8+, FastAPI, Uvicorn
- **Database**: In-memory (SQLAlchemy ready)

## 📊 API Endpoints

- `GET/POST/PUT/DELETE /api/expenses` - Expense management
- `GET/POST/PUT/DELETE /api/team` - Team management
- `GET/POST/PUT/DELETE /api/invoices` - Invoice management
- `GET/POST/PUT/DELETE /api/categories` - Category management
- `GET/PUT /api/settings` - Settings management
- `GET /api/csv/export` - Export CSV
- `POST /api/csv/import` - Import CSV
